# 逐题审阅一页指南

只判断当前题目的原文，不从另一种表述、机器元数据或常识补要求。机器草稿是待核对的建议；练习与浏览器提交都不是正式 gold。

1. 先读常驻原文，再检查每条要求的对象、数量、关系、单位、事件与先后。字段的中文名称和提示来自同一展示词典；未翻译的角色/事件字符串保留原标记，需对照英文原文，不能把名称猜成新要求。
2. 分清“必须满足”“允许但不强制”“禁止项”。出现方向只由极性决定，禁止层不会再取反：正常禁止项要求“不出现”，禁止层却标“要求出现”时需交给专家核对。数量未限定、可选、精确数字不得互换。
3. 原文依据单独显示。机器元数据、风险等级和截取上下文都可能只是建议；无有效原文位置时会明说，不能当成已证明。事件缺少角色、触发或结束信息时，展示层不会补写。
4. 草稿错误就修改、排除、拆分、合并或新增。排除只代表“不把这条草稿计分”，不自动表示“禁止出现”。不会判断或原文有误就保留编辑并暂存，交给维护者处理。
5. 只有看完完整语义且无未解决问题才能明确确认。未知字段完整保留并显示警告，整题快捷确认不可用；不要靠重置草稿消除警告。修改已确认内容后必须重新确认。

CPD 用来核对哪些细节可以有不同安排。逐项选择“原文允许这些变化”“原文限制了这些变化”或“信息不足，无法判断”，最后检查是否遗漏可变化的细节。每项默认未选；有异议时在该项下填写原因，无需重复写入全题备注。修改要求后需要重新判断 CPD。

普通标注者无需打开“维护者技术资料”。整题提交只确认可见的文字判断；目标选择、分箱和平台实现由维护者另行核对。技术核对未完成不能生成正式 gold，有异议的题也不能定稿。正式校验与全套定稿由维护者执行。

练习见同目录 practice.json：先独立选“必须／允许／禁止／排除／暂存”，再看解释。练习不会写入真实题包。
