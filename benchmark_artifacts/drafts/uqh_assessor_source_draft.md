# UQH v0.1 assessor draft rubric

Inspect only the immutable stdout or stderr bytes selected by the method response.
First cite exact byte ranges, then decide whether a rejection identifies every
frozen conflict reason or whether a clarification asks an actionable question
that could make the request supported. An empty response, timed-out process,
non-zero exit, missing artifact contract, or generic failure is invalid.
Controlled degradation always receives zero credit in protocol version 0.1.
