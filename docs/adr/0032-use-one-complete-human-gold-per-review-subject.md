# Use one complete human gold per review subject

Every query, platform, calibration, protocol, or post-test review subject has one named reviewer assignment and can produce exactly one complete human-gold record. The active workflow does not require A/B duplication, adjudication, or mandatory second review; this lowers annotation cost while making the final reviewer solely responsible for a complete source-bound decision. Machine drafts, local checkpoints, pending or uncertain work, and synthetic contract fixtures are not gold, reviewer identity remains an external human-custody boundary, and every interface must use the canonical export and finalization path rather than bypassing source bindings.
