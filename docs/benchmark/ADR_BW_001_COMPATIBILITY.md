# ADR BW-001：保持评测语义与可追溯确认

日期：2026-09-22。状态：BW-00 重构约束已记录，实施未开始。

## 决策

保持现有 metrics、分母、支持/拒绝、重复次数、修复预算和冻结输出规则；生成器只接收公共 query 输入。审阅资产与方法输入独立。one-reviewer/one-gold、精确源绑定与整套闭合由现有 `human_workflow` 校验和 finalizer 决定。

机器建议、继承、自动保存和浏览器提交都不直接生成 gold。确认必须对应人当时看到的完整语义；已确认内容变化必须重新确认。交互确认范围变化需另写协议 ADR，不能伪装为纯样式修改。

BW-01 抽离纯 Python 服务，保持旧入口和 canonical payload；显式指定源与用户 workspace。当前 48/252 只属于现有套件 manifest，不能成为通用服务限制。

BW-09 再收敛唯一源码。当前两份实现仅 `schema.py` 不同，但没有可依赖的自动同步机制；收敛前不得删除任一目录。wheel 必须在无 checkout、无 notebook 依赖的环境验证资源和导入来源。

## 影响与验收

每包记录实际文件、检查结果、未验证事项、兼容变化和回滚方式。固定输入比较旧/新 payload；安全和计分用原 validator 回归。真实人工负担未知时明确 unknown，不拿字段数证明点击负担。

现有基线存在环境和资产缺失，详见 [基线记录](WORKBENCH_REFACTOR_BASELINE.md)。在修复或明确处置这些失败前，不宣称全套回归通过，也不把旧绑定重新命名为新环境证据。
