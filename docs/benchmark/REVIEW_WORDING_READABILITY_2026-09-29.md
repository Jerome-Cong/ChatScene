# 标注卡片文案修订（2026-09-29）

针对“允许但不强制；出现或成立；道路配置；取值：否”等片段要求标注者自行推断指代的问题，卡片改成：具体描述、本条作用、逐项参数。机器备注在独立折叠区，常见备注给出中文解释并保留原文；机器资料与原文片段明确区分，内部字段在来源记录中保留。

例如，道路设施为 false 且为 permitted 时显示：

> 草稿描述：场景中没有人行横道区域。
>
> 本条作用：本条是可选描述。场景是否符合这项描述，都不会因本条扣分。

“没有设施”不自动解释成“禁止出现设施”。禁止项要求遵守描述中的“不应出现”，不再次取反；禁止层与正向极性冲突仍提示专家核对。零数量否定保留既有评分解释。未知字段、原始参数、权重及备注不丢失，未明确的角色与事件条件不补写。

实现：`review_wording.py` 管理 Python/浏览器共享模板，随题包 dictionary 绑定。旧确认通过原迁移流程重新审阅，不自动套用新解释；旧题包与备份不覆盖。旧 notebook 的主要卡片也按句子换行。计分、源题库/oracle、compiler/finalizer 均未改变。

验证：39 项 Python 展示/packet/model/migration/固定兼容测试通过（2.864 秒）；16 项真实离线浏览器回归通过（5.881 秒），包含 Python/JS 完整句一致与备注折叠；旧 notebook 59 项初轮58通过、1项因 HTML 换行断言失败，保留原内容断言并规范化换行后该项定向复验通过。实际导出卡片已用 Chromium 截图和可见文本复核，独立 reviewer 两轮阻断修复后通过。未执行新一轮真人试标。
